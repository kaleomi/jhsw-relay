        天赋

        通关得星：每张地图的普通 / 困难 / 炼狱各 1 颗，无尽模式超过剧本 10 波再得 1 颗，每赢一次每日挑战得 1 颗。星星用来点天赋，可以随时重置。全队效果的天赋（标 ◆）在联机时以房主的为准。

        排行榜

        无尽模式结束（水晶被摧毁，或在暂停菜单里「结算并退出」）时自动上传。分数 =（到达波次 × 1000 + 击杀 × 2 + 剩余水晶 × 5）× 难度系数（困难 ×1.4，炼狱 ×1.9）× 突变系数。

          图鉴

          触屏：左半屏拖动移动（推到底冲刺），右半屏滑动转视角；右下角开火 / 跳跃 / 换弹 / 手雷 / 轨道打击 / 瞄准 / 切枪；顶部陷阱栏点选后按「放置」；走近机关或科研舱、对准陷阱时，屏幕下方会出现互动、升级、拆除按钮。按钮位置可以在 设置 → 触屏按钮 里调整。
