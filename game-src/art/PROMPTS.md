# 晶核守卫 · 美术图片清单

前四部分的 19 张图都已经放进来了（`*.webp`，原图生成记录见 `generation-prompts.json`）。想换哪张，就用同样的文件名覆盖（png / jpg / webp 都行），重新构建即可。
第五～七部分（图标和怪物头像）是 v3.4 新增的，还没有图：放进来之后陷阱栏、军械库、图鉴、任务简报会自动换成图片，没放的继续用线条图标。
每一张都是可选的：删掉哪张，游戏就继续用原来的简笔图标 / 3D 场景，不会出错。

- 格式：png / jpg / webp 都行，构建时会自动居中裁剪、缩小并压成 webp（头像 256×256，横图 960×540，海报 1600×900）。
- 尺寸：头像用 **1024×1024**；其余用 **1536×1024**（横版）。构建会从正中间裁成 16:9，所以**主体放在画面中间**，上下边缘留点余量。
- 画面里**不要出现文字、字母、水印或 Logo**。
- 先把下面的「统一画风」发给 ChatGPT，再一张一张发具体描述，这样整套图风格一致。
